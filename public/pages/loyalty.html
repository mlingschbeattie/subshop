Run atob(localStorage.getItem('loyalty_token')) in the console. The token is just Base64, not encryption — it reveals PII: email, SSN, credit card number, and a secret flag.
⚠ Suspicious cookie detected: admin_override=true — this action has been logged.
You clicked "Claim Free Drink" and your browser silently set a cookie called admin_override. Every subsequent request includes that cookie — the server can read it, log it, or flag your account.
Lesson: Cookies are not invisible. Don't assume you can set one without the server detecting it.

Base64 is not encryption — it's just encoding. Anyone who sees the string can decode it instantly. Storing sensitive data this way provides zero protection.

      
Think of it like: Writing a secret in pig latin and calling it a code — anyone who knows the trick can read it.

      
Real world: 2019 Facebook stored hundreds of millions of passwords in plaintext internal logs.
