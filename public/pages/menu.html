📁 Case File — Broken Access Control
SituationThe Sub Shop's menu page hides staff-only items behind a URL parameter. Access control is enforced entirely in client-side JavaScript.
At RiskInternal pricing, supplier costs, unreleased menu items — visible to anyone who discovers the right parameter.
Your RoleFind the hidden parameter that reveals staff content. Prove that client-side role checks are never enough.

Add ?role=staff (or ?role=admin) to the URL. The page JavaScript checks URLSearchParams and reveals hidden staff-only menu items and internal pricing. This is purely client-side — no server validation.

Access controls that only exist in the browser can be bypassed by anyone who looks at the URL. If the server doesn't enforce authorization, the client-side check is just decoration.

Think of it like: A "Staff Only" door that's just labeled, not locked — anyone can push it open.

Real world: 2021 Parler breach — sequential API IDs with no auth checks exposed 70TB of user data.
