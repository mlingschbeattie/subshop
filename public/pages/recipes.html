📁 Case File — Vulnerable Components
SituationThe recipes page loads a third-party nutrition parsing library. Libraries carry their own vulnerabilities — check the version.
At RiskApplication integrity — a vulnerable dependency can be exploited without touching any of your own code.
Your RoleIdentify the vulnerable library, find its CVE, and exploit the prototype pollution vulnerability.

        CVE-2023-18912 — Critical RCE in subutils <= 1.4.0

        parseIngredients() uses eval() on unsanitized input. An attacker who can
        supply an ingredient string can execute arbitrary JavaScript.

        Fix: Upgrade to subutils >= 2.0.1

Using outdated libraries means inheriting their unpatched vulnerabilities. Even if your code is perfect, a vulnerable dependency can give attackers a way in.

      
Think of it like: Taking expired medication because "it probably still works" — the side effects are unpredictable and dangerous.

      
Real world: CVE-2019-11358 — jQuery prototype pollution affecting thousands of sites worldwide.
