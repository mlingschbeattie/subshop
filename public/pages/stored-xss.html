Vulnerable Code

Server stores raw HTML; client renders with innerHTML:

// Server — stores raw HTML
app.post('/api/review', (req, res) => {
  db.prepare('INSERT INTO reviews ...')
    .run(author, content); // VULNERABLE
});

// Client — renders raw
reviews.forEach(r => {
  div.innerHTML += r.content; // XSS!
});

// Safe alternative:
div.textContent = r.content;
🦆

Stored XSS means the malicious script is saved in the database and runs for every user who loads the page. Unlike reflected XSS, the attacker doesn't need the victim to click a special link — just visiting the page is enough.

Think of it like: Leaving a trap in the guestbook that activates every time someone reads it.

Real world: 2018 British Airways — stored XSS used to exfiltrate 500K customer payment records over two weeks.
